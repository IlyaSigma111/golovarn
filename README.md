# ГОЛОВА

**ASCII-череп аватар** — Electron-приложение для стриминга/выступлений. Рисует анимированный череп символами на Canvas 2D с эффектами, мимикой, сценариями и визуализацией звука.

## Возможности

- 🦴 **ASCII-череп** — символьная сетка, масштабируемая голова с мимикой (глаза, рот, моргание, саккады)
- 🎵 **Визуализация звука** — визуализатор, волны, реакция рта на амплитуду
- ✨ **9 эффектов** — терминал, матрица, помехи (glitch), тревога, символы (code particles), волны, визуализатор, эрозия, рассыпание (shatter)
- 🎬 **Сценарии** — последовательности аудио/видео/эффектов/эмоций, автовоспроизведение
- 🖥 **Окно визуализации** — отдельное окно для OBS/проектора, синхронизация состояния
- 🎨 **Цветовые режимы** — зелёный/красный/белый с плавным свипом
- ⏯ **Пауза** — пауза сценария (аудио + видео + эффекты)
- 📹 **Видео** — воспроизведение видео с кроссфейдом и головой в углу

## Запуск из исходников

```bash
git clone https://github.com/cssigma/golovarn.git
cd golovarn
npm install
npm start        # dev-режим
npm run dist     # собрать установщик
```

## Стек

- **Electron 22** (Chromium 108, Windows 8+)
- **React 18** + **TypeScript**
- **Vite** (сборка)
- **Canvas 2D** (отрисовка)

## Структура

```
src/
  skull/        — движок: renderer, effects, canvas, faceAnim
  state/        — hub (состояние, сценарии, эффекты)
  audio/        — AudioPlayer, MusicPlayer
  video/        — VideoPlayer
  pages/        — MainPanel, VizPage
  ui/           — компоненты интерфейса
electron/
  main.js       — главный процесс
  preload.js    — IPC-мост
```

## Последние изменения (v0.1.4)

- Плавное появление/исчезание **всех эффектов** через `ctx.globalAlpha` (идентично голове)
- Фикс: символы (code particles) были белыми вместо зелёных
- Сценарии запускаются без аудио/видео (только эффекты + эмоция)
- Фикс краша `syncBaseMask` при смене размеров модели в окне визуализации
- Экспоненциальный fade (rate=4, `dt*4`) — спад виден сразу, хвост мягкий
